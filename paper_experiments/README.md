# Paper Experiments

This directory is reserved for future SCI-track experiment manifests, result
indexes, and lightweight reproducibility notes.

Paper-Stage 0 does not add training outputs here. Do not commit large result
artifacts, raw datasets, checkpoints, or run directories.

Expected future use:

- Experiment manifests.
- Promoted full-run result indexes.
- Multi-seed summary tables that point to external or ignored run directories.
- Notes linking paper tables to reproducible commands.
