\chapter{模型方法与融合结构}

\section{写作占位}

本章为模型方法占位。正式正文应按证据源中登记的模型矩阵介绍 I/Q-only、STFT-only、I/Q+STFT static fusion、gated fusion、CLDNN、MCLDNN、LWAMCNet 和 parameter-matched I/Q control 的角色。

\section{声明边界}

本章可以解释各模型在本实验中的输入视图与比较目的，但不得把 gated fusion 写成已验证的鲁棒方法，不得把 static fusion 写成广义优越方案，也不得新增未在 Stage 5A/5B 主协议中完成的模型结果。
