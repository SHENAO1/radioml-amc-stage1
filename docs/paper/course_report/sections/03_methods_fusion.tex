\section{I/Q 序列基础模型}

I/Q 序列基础模型直接以形状为 $[B,2,L]$ 的基带信号张量作为输入，其中两个通道分别对应同相分量与正交分量。该类模型不显式构造时频图，也不引入额外视图，因此适合作为检验其他结构是否带来额外信息的基础参照。相关实现见 \path{src/radioml_amc/models/cnn1d.py}、\path{src/radioml_amc/models/resnet1d.py} 以及模型构建函数 \path{src/radioml_amc/training/trainer.py}。

\path{cnn1d} 采用顺序一维卷积、批归一化、ReLU 激活、池化和全局池化，将 I/Q 序列映射为固定长度表征后进行调制类别分类。其作用是提供一个结构直接、可解释的时域卷积基线。设输入为 $x_{\mathrm{IQ}}\in\mathbb{R}^{2\times L}$，该类模型可抽象表示为
\begin{equation}
  h_{\mathrm{IQ}} = f_{\mathrm{1DConv}}(x_{\mathrm{IQ}}), \qquad
  \hat{y}=c(h_{\mathrm{IQ}}),
  \label{eq:cnn1d-abstraction}
\end{equation}
其中 $f_{\mathrm{1DConv}}$ 表示一维卷积特征提取器，$c(\cdot)$ 表示分类头。

\path{resnet1d} 同样使用 I/Q 输入，但在卷积堆叠中加入残差连接。残差块将卷积分支与 shortcut 分支相加后再经过非线性激活，目的在于提供与普通一维卷积不同的深层时域建模结构。本文只将其作为协议内 I/Q baseline 之一，不在本章讨论其结果表现。

\section{时序模型与轻量模型}

时序模型用于在卷积局部特征之上引入序列建模机制。本文纳入 \path{cldnn} 与 \path{mcldnn} 两个 I/Q-only 时序模型，它们均在 \path{src/radioml_amc/models/baselines.py} 中实现，并在 \path{src/radioml_amc/models/__init__.py} 与 \path{src/radioml_amc/training/trainer.py} 中注册为可训练模型。相关模型来源引用将在最终报告定稿阶段补充。
% TODO: add CLDNN/MCLDNN/LWAMCNet citation

\path{cldnn} 使用一维卷积网络提取 I/Q 局部模式，再将卷积输出转置为时间序列形式输入 LSTM，最后使用全连接分类头输出调制类别 logits。其方法抽象为
\begin{equation}
  u_t = f_{\mathrm{conv}}(x_{\mathrm{IQ}})_t,\qquad
  h = f_{\mathrm{LSTM}}(u_1,\ldots,u_T),\qquad
  \hat{y}=c(h).
  \label{eq:cldnn-abstraction}
\end{equation}
该模型在本报告中作为卷积-序列混合结构对照存在，本章不对其结果作排序性描述。

\path{mcldnn} 也是协议内 I/Q 模型。源码中该模型包含联合 I/Q 空间卷积分支、独立 I/Q 因果卷积分支、后续融合卷积、LSTM 与多层分类器。该结构的纳入目的在于覆盖 MCLDNN-style 的多分支时序建模思路。根据第 2 章协议，\path{mcldnn} 的三个训练种子均保留在 Stage 5A/5B 证据内；本章只说明其结构角色，异常细节和解释边界留待第 4 章与第 5 章讨论。

\path{lwamcnet} 作为轻量模型纳入比较。其实现使用二维卷积起始层、depthwise separable convolution residual stack、grouped depthwise convolution reconstruction 与线性分类头，目标是在 I/Q 输入上提供较低参数量的结构参照。本文不在方法章节中将“轻量”直接等同于效率或部署优势；复杂度与延迟范围仍以第 2 章定义的受控证据为准。

\section{STFT 时频分支}

除原始 I/Q 序列外，本文还纳入 STFT 视图对应的 \path{tfcnn_stft} 模型。该模型由 \path{src/radioml_amc/models/multiview.py} 中的 \path{TimeFrequencyCNN} 实现，使用 \path{TimeFrequencyBranch2D} 对二维时频输入进行卷积、归一化、激活、池化和自适应池化，再接线性分类层输出调制类别。

从方法动机看，STFT 视图提供了与时域 I/Q 序列不同的观测方式。I/Q 序列强调时间采样点上的相位与幅度关系，而 STFT 视图将局部频率结构显式展开，有助于在方法层面检验时频表征能否提供互补信息。设 STFT 输入为 $x_{\mathrm{STFT}}$，单视图时频分支可写为
\begin{equation}
  h_{\mathrm{STFT}} = f_{\mathrm{2DConv}}(x_{\mathrm{STFT}}),\qquad
  \hat{y}=c(h_{\mathrm{STFT}}).
  \label{eq:stft-branch-abstraction}
\end{equation}
该节仅描述 STFT 分支的输入与结构，不评价其相对有效性。

\section{参数匹配 I/Q 控制模型}

\path{iq_param_matched} 是本实验中的参数匹配 I/Q-only 控制模型，对应 \path{src/radioml_amc/models/baselines.py} 中的 \path{ParameterMatchedIQOnlyNet}。该模型仍只使用 I/Q 输入，但通过调整一维卷积通道数和分类头规模，使其参数预算接近融合模型的量级。其设置目的不是提出新的 AMC 架构，而是为融合解释提供控制条件。

引入该控制模型的理由在于，多视图融合模型通常会增加分支、投影或分类器参数。如果只比较融合模型与较小的 I/Q baseline，可能难以区分性能变化来自额外输入视图，还是来自参数量增加。参数匹配控制模型将输入视图固定为 I/Q，从而为后续分析提供更清晰的对照。本文在本章只说明控制变量设计，不写其与其他模型的结果胜负。

\section{静态 I/Q-STFT 融合}

\path{fusion_iq_stft} 是本实验中的静态 I/Q-STFT 融合候选，由 \path{src/radioml_amc/models/multiview.py} 中的 \path{MultiViewFusionNet} 实现。该模型包含两个分支：I/Q 分支使用一维卷积提取 $h_{\mathrm{IQ}}$，STFT 分支使用二维卷积提取 $h_{\mathrm{STFT}}$；随后将两个分支的表示拼接并输入分类器。其基本形式可写为
\begin{equation}
  h_{\mathrm{IQ}} = f_{\mathrm{IQ}}(x_{\mathrm{IQ}}),\qquad
  h_{\mathrm{STFT}} = f_{\mathrm{STFT}}(x_{\mathrm{STFT}}),
  \label{eq:static-fusion-branches}
\end{equation}
\begin{equation}
  z = [h_{\mathrm{IQ}}, h_{\mathrm{STFT}}],\qquad
  \hat{y}=c(z).
  \label{eq:static-fusion}
\end{equation}

该结构的研究作用是检验在同一固定协议下，显式引入时频视图后模型行为如何变化。本文将其称为待评估 fusion candidate，而不是预设其相对 I/Q-only 模型具有广义优越性。后续任何关于该模型的解释均必须回到第 2 章定义的固定划分、三种子汇总与统计检验协议。

\section{门控 I/Q-STFT 融合}

\path{gated_fusion_iq_stft} 是本实验中的门控 I/Q-STFT 融合候选，由 \path{src/radioml_amc/models/gated_fusion.py} 中的 \path{ScalarGatedIQSTFTFusionNet} 实现。该模型同样包含 I/Q 分支与 STFT 分支，但在投影到相同融合维度后，通过一个标量 gate 调节两个视图表示的组合比例。源码中的 gate 输入包含两个投影表示、二者绝对差以及逐元素乘积：
\begin{equation}
  r = [z_{\mathrm{IQ}}, z_{\mathrm{STFT}}, |z_{\mathrm{IQ}}-z_{\mathrm{STFT}}|, z_{\mathrm{IQ}}\odot z_{\mathrm{STFT}}],
  \label{eq:gated-input}
\end{equation}
\begin{equation}
  g=\sigma(W_2\,\phi(W_1 r)),\qquad
  h=(1-g)z_{\mathrm{IQ}}+g z_{\mathrm{STFT}},
  \label{eq:gated-fusion}
\end{equation}
其中 $g$ 为样本级标量门控权重，$\sigma(\cdot)$ 表示 sigmoid 函数，$\phi(\cdot)$ 表示非线性激活。分类器随后基于融合表示 $h$ 输出调制类别 logits。

需要注意的是，该 gate 不接收显式 SNR 输入，其设计目的是在固定模型矩阵中提供一个可检验的视图加权机制。本章只描述其实现方式与实验角色，不写“门控提升鲁棒性”或类似结果性表述。

\section{方法边界}

本报告并不声称提出全新的 SOTA 架构。第 3 章的任务是清晰记录 Stage 5A/5B 主实验中已经登记并完成的模型方法，使后续结果分析能够追溯到明确的输入视图、模型标识和代码实现。模型来源与相关工作引用将在最终报告定稿阶段补充。

Stage 6B 文档中出现的 \path{fusion_iq_amp_phase}、low-SNR weighted cross entropy、cheap signal augmentation、\path{tcn_gru}、\path{mcldnn_stable_v2} 等方向，只属于 diagnostic candidates 或 planning items。它们不构成本章主实验模型矩阵的一部分，也不能被写成已完成主实验。即使其中某些 mock smoke 路径已经存在，也只能说明工程路径或 artifact writer 可运行，不能支持第 4 章主结果或方法优越性结论。
