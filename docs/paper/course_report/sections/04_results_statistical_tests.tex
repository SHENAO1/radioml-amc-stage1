\section{配对统计检验结果}

为避免仅依赖聚合均值，本实验进一步使用 predictions archive 中的 \path{predictions_test.csv} 进行配对统计检验。配对键为 \path{split_id + train_seed + sample_id}，bootstrap accuracy delta 的定义为
\[
  \Delta = \operatorname{Acc}(\text{model\_a})-\operatorname{Acc}(\text{model\_b}) ,
\]
resamples 为 10,000，随机种子为 42。McNemar 检验使用同一批 paired sample 的正确/错误二元结果构造列联表。本节只讨论已在 \path{paired_bootstrap_accuracy_deltas.csv} 与 \path{mcnemar_tests.csv} 中存在的比较，不扩展到未检验组合。

\section{低信噪比下的融合权衡}

本报告将低信噪比区域定义为 \lowSNR{}。在 \path{low_snr_table.csv} 中，每个训练种子对应 17,600 个 low-SNR 测试样本，三种子合计用于配对统计检验的样本数为 52,800。主表摘录显示，\path{cldnn} 的 low-SNR accuracy 为 $0.222386$，\path{fusion_iq_stft} 为 $0.221326$，\path{iq_param_matched} 为 $0.216345$。

相对于 \path{cldnn}，\path{fusion_iq_stft} 在 low-SNR scope 上的 bootstrap delta 为 $-0.001061$，95\% 置信区间为 $[-0.003939,0.001838]$，该区间跨越 0；对应 McNemar 检验 $p=0.476423$。因此，在当前 paired low-SNR 检验下，不能声称静态 I/Q-STFT 融合优于 \path{cldnn}。

相对于参数匹配 I/Q 控制模型 \path{iq_param_matched}，\path{fusion_iq_stft} 在 low-SNR scope 上的 bootstrap delta 为 $0.004981$，95\% 置信区间为 $[0.001970,0.007973]$，McNemar 检验 $p=0.001063$。但是同一比较在 overall scope 上的 bootstrap delta 为 $-0.017364$，95\% 置信区间为 $[-0.019288,-0.015470]$。因此，静态融合在本协议中的证据边界应表述为 low-SNR 局部小幅正向与 overall penalty 并存的 trade-off，而不是广义融合优越性。

\section{门控融合结果}

\path{gated_fusion_iq_stft} 的 overall accuracy 为 $0.571947$，low-SNR accuracy 为 $0.211307$。与之相比，静态融合 \path{fusion_iq_stft} 的 overall accuracy 为 $0.577098$、low-SNR accuracy 为 $0.221326$，\path{cldnn} 的 overall accuracy 为 $0.612932$、low-SNR accuracy 为 $0.222386$。因此，在当前固定划分和三种子聚合结果中，门控融合行在 overall 与 low-SNR 两个指标上均低于静态融合行和 \path{cldnn} 行。

配对检验进一步支持该负结果。对于 \path{gated_fusion_iq_stft} vs. \path{fusion_iq_stft}，overall bootstrap delta 为 $-0.005152$，95\% 置信区间为 $[-0.006841,-0.003462]$，McNemar 检验 $p=2.43\times10^{-9}$；low-SNR bootstrap delta 为 $-0.010019$，95\% 置信区间为 $[-0.012746,-0.007292]$，McNemar 检验 $p=1.23\times10^{-12}$。由于 delta 定义为 gated minus static，负值和 McNemar 方向共同指向静态融合在该比较中更强。基于这些证据，本报告不能写作“门控融合提升鲁棒性”或类似结论。

\section{MCLDNN 异常与负结果保留}

\path{mcldnn} 行在主表中的 overall accuracy 为 $0.250083$，macro-F1 为 $0.199852$，标准差明显高于其他模型行。根据 \path{PAPER_STAGE5B_RESULT_AUDIT_AND_TABLES.md} 与 \path{section5_5_mcldnn_anomaly_retained_negative_evidence.md}，该聚合值包含三个训练种子，其中 seed 42 的 test accuracy 为 $0.568432$，而 seed 2025 和 seed 3407 分别出现 chance-level collapse，二者 test accuracy 均为 $0.090909$，macro-F1 均为 $0.015152$。这些结果已经按协议保留在主表中，没有进行 seed 清洗或主表重算。

该异常限制了 \path{mcldnn} 行在本报告中的解释方式：它可以作为当前训练配置下的负结果与优化敏感性证据，但不应被用作经过修复后的模型性能结论。与此同时，保留 failed seeds 并不推翻完整 fixed-split 3-seed benchmark 的有效性，因为其余模型行仍遵循相同的数据划分、训练种子集合、评估脚本和 predictions archive 记录。Stage~6B 中与稳定化或候选结构相关的 smoke/diagnostic 项目只能作为后续诊断线索，不得写成本章主结果或修复后结论。
