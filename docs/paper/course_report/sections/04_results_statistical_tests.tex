\textbf{关于配对统计检验的说明。}本章配对统计检验所用样本来自按（调制类别 $\times$ SNR）联合分层构成的固定测试集，同 cell 内样本不完全独立。报告的 McNemar $p$ 值以独立样本为假设，因此实际 Type-I 错误率可能被低估；在 $n = 44{,}000$ 的大样本量下，任何系统性微小差异都会产生极小 $p$ 值，但这并不等同于强效应量。本章以效应量（准确率差值）与 95\% 置信区间作为主要证据，$p$ 值仅作辅助判断；所有仅 $p < 0.001$ 的项统一标注为 ``$p < 0.001$''，决策相关的临界 $p$ 值（如 $p = 0.0155$、$p = 0.476$、$p = 0.941$）保留具体数值。

\subsection{低信噪比互补性图谱分析}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.95\textwidth]{fig14_paired_disagreement_by_snr.pdf}
  \caption{关键模型对在各 SNR 点的配对正确性净分歧（``仅 A 正确'' 占比 $-$ ``仅 B 正确'' 占比，predictions\_test.csv 三种子聚合）。}
  \label{fig:paired-disagreement-by-snr}
\end{figure}

图~\ref{fig:paired-disagreement-by-snr} 是解释低信噪比融合权衡的核心证据。它不是把两个模型的平均准确率相减，而是统计同一测试样本上“模型 A 正确、模型 B 错误”和相反方向的分歧比例，因此可以观察互补性出现在哪些 SNR 点。若 STFT 视图提供稳定互补，静态融合相对 I/Q 参照模型应在低信噪比区间持续出现正向净分歧；实际结果更像局部互补与局部损失的混合图谱。

相对 \path{iq_param_matched}，静态融合在 \(-14\)、\(-12\)、\(-10\) dB 的净分歧分别约为 \(+1.08\)、\(+1.74\)、\(+1.94\) 个百分点；STFT 视图在 \(-14\) 至 \(-10\) dB 区间表现出方向一致的局部正向净分歧，但单点幅度未达统计显著（单 SNR 点约 3,300 个配对样本，+1 pp 量级差异 95\% CI 宽度约为 $\pm 1.0$ pp）。在 \(-8\) 和 \(-6\) dB，净分歧转为 \(-0.80\) 和 \(-0.36\) 个百分点，表明这种局部正向分歧没有覆盖整个低信噪比区间。相对 \path{cldnn} 时，静态融合在 \(-14\) 和 \(-10\) dB 有 \(+1.35\) 和 \(+1.24\) 个百分点的局部正向净分歧，却在 \(-8\) 和 \(-6\) dB 出现 \(-1.77\) 和 \(-1.76\) 个百分点的反向分歧。这解释了为什么低信噪比总差值为 \(-0.001061\) 且置信区间跨 0：融合不是全局领先，而是在不同 SNR 点上互相抵消。

\textbf{关于单点不确定性的补充。}单 SNR 点的净分歧基于约 3,300 个配对样本（三种子合并），单点 +1 pp 量级差异的 95\% 置信区间宽度约为 $\pm 1.0$ pp，多个个别点的局部正向分歧在该不确定性下不可单独声明显著。本节的解释基于多点方向一致的整体图谱，不依赖任何单点差异。

门控融合的分歧图进一步强化负结果判断。相对静态融合，门控融合在 \(-16\) 到 \(-6\) dB 多数点为负向净分歧，其中 \(-10\) dB 约为 \(-2.50\) 个百分点，\(-12\) dB 约为 \(-1.65\) 个百分点。这说明当前标量门控没有学到“低信噪比时增加 STFT、较高信噪比时回退 I/Q”的有效策略，反而在静态融合已有局部收益的位置损失了样本。

相对于 CLDNN，静态 I/Q--STFT 融合的低信噪比准确率差值为 \(-0.0011\)，95\% 置信区间为 \([-0.0039,+0.0018]\)，区间跨越 0；McNemar 检验 \(p = 0.476\)。这组证据支持"接近但未优于 CLDNN"的解释。

相对于参数匹配 I/Q 控制模型，静态融合的低信噪比准确率差值为 0.0050，95\% 置信区间为 \([0.0020,0.0080]\)，McNemar 检验 \(p = 0.001\)。但同一比较在整体测试集上的准确率差值为 \(-0.0174\)，95\% 置信区间为 \([-0.0193,-0.0155]\)。因此，合理结论是：STFT 视图在本实现中测得低信噪比局部小幅正向差值，但伴随整体准确率下降。

图~\ref{fig:low-snr-class-recall-delta} 进一步说明，静态融合的低信噪比差异并非对所有调制类别同向。相对 \path{iq_param_matched}，静态融合在 QAM16 上减少 \(7.4\) 个百分点召回率，却在 QAM64 上增加 \(8.9\) 个百分点召回率，接近等幅、方向相反。这一现象提示 STFT 视图可能改变了 QAM16/QAM64 间的判别边界。一个合理的待检验假设是：STFT 幅度视图强调局部频谱能量而弱化了 I/Q 序列中的细粒度星座几何，使分类器在两个相似 QAM 类别间的边界发生整体偏移，更多 QAM64 被保留下来而部分 QAM16 被吸收到相邻区域。但本文未做 logits 分布检查、STFT 分支消融或梯度显著性归因等验证实验，因此该机制保留为待检验假设，不作为已确立的结论。附录图~\ref{fig:low-snr-confusion-panels} 给出代表模型在低信噪比范围内的行归一化混淆矩阵，作为类别混淆解释的补充。

\section{门控融合负结果}

\path{gated_fusion_iq_stft} 的整体准确率为 0.5719，低信噪比准确率为 0.2113，均低于静态融合 \path{fusion_iq_stft}。配对检验也支持这一判断：门控融合相对静态融合的整体准确率差值为 \(-0.0052\)，95\% 置信区间为 \([-0.0068,-0.0035]\)，McNemar 检验 \(p < 0.001\)；低信噪比范围内的差值为 \(-0.0100\)，95\% 置信区间为 \([-0.0127,-0.0073]\)，McNemar 检验 \(p < 0.001\)。

由于差值定义为"门控融合减静态融合"，上述负值说明当前标量门控机制没有改善静态融合。本文因此将门控融合作为负结果保留，不写作"门控提升鲁棒性"或"门控融合整体准确率高于静态融合"。

本文未对当前门控失败做完整机制诊断，但可登记三类待检验假设：（i）门控权重 $g$ 可能退化为接近常数，使融合实际上回退为静态加权平均；（ii）门控输入特征（绝对差与逐元素乘积）可能在不同 SNR 下区分度不足，使 $g$ 与 SNR 缺乏关联；（iii）当前 sigmoid 标量门控的容量可能不足以表达「低 SNR 增 STFT、高 SNR 退回 I/Q」的策略。验证这些假设需要 $g$ 值分布的逐 SNR 直方图、$g$ 与 SNR 的相关分析、以及与多头/向量门控的对照实验，留作后续工作。

这些数值说明同一受控测量条件下不同模型的参数量和 CUDA 前向耗时背景。例如，CLDNN 参数量较高但前向延迟并非最高；门控融合参数量低于 CLDNN，却具有更高的受控前向延迟。CPU 延迟、FLOPs/MACs 和 STFT 预处理完整耗时需要独立测量协议支撑。

\textbf{关于 MACs 与部署效率的关系。}需要注意，MACs 与实测前向延迟的关系并非单调：\path{fusion_iq_stft} MACs 仅 2.0 M 但批量 1 延迟 1.84 ms，\path{cldnn} MACs 8.7 M 但批量 1 延迟仅 1.31 ms。差异主要来自 STFT 分支 2D 卷积结构与现代 GPU 上 1D 卷积的不同优化路径，而非纯算量。这说明 MACs 不是部署效率的可靠代理；第~\ref{sec:results-extended-summary}~节以参数量论证 I/Q 分支表征容量，而非以 MACs 论证。

\section{MCLDNN 异常与负结果保留}\label{sec:mcldnn-anomaly}

\path{mcldnn} 三个训练种子的整体准确率为 0.5684 / 0.0909 / 0.0909，宏平均 F1 为 0.5891 / 0.0152 / 0.0152。其中 seed 42 收敛到 0.5684；seed 2025 和 seed 3407 单类塌陷至 11 类均匀基准 0.0909（宏平均 F1 0.0152），表现为近似随机水平的单类预测。seed 42 在低/中/高 SNR 子集上的准确率分别为 0.2121 / 0.7729 / 0.8391。三种子数据构成双峰分布，mean $\pm$ std 假定的单峰/正态结构不成立，因此\textbf{本章后续所有 MCLDNN 与其他模型的整体准确率比较均基于 seed 42 单种子结果（0.5684），并在比较时明确注明}；三种子均值（0.2501）仅用于训练稳定性讨论，不参与模型间排序（表~\ref{tab:course-main-results-excerpt} 脚注已注明）。

本文保留这两个异常种子，因为它们属于已登记的固定协议运行。删除异常种子并重算主表会改变实验协议，也会掩盖训练稳定性问题。协议纪律要求主表保留 3 个训练种子的完整结果；研究责任则要求对失败形态给出可检验解释，避免把异常简单归为“随机坏运气”。

当前可提出三类诊断假设。第一，学习率与权重衰减组合可能不适合 MCLDNN：全模型统一使用学习率 \(10^{-3}\)、权重衰减 \(10^{-4}\)、batch size 256，有利于协议对齐，但对多分支卷积、融合卷积和 LSTM 串联的结构未必公平。第二，初始化敏感性可能更强：seed 42 正常收敛而 seed 2025/3407 塌陷，提示某些初始门控、卷积核或循环层状态可能把梯度引向退化分类头。第三，输入格式或维度排列可能与该实现的结构假设不完全匹配：MCLDNN 常依赖对 I/Q 分支、时间维和通道维的特定组织方式，若实现中的 reshape、permute 或分支拼接与预期不一致，模型可能在部分初始化下无法形成有效类别边界。

因此，沿用统一超参对 MCLDNN 公平性不足。统一学习率、权重衰减和 batch size 的优点是避免为单个模型做事后调参，保证主表比较纪律；缺点是把结构稳定性、优化敏感性和超参适配能力混在一起。更负责的后续诊断应预先登记 MCLDNN 专用学习率网格、初始化重复、梯度范数监控、输入张量形状单元测试和早期 logits 分布检查，并在新的输出目录中形成独立证据。附录图~\ref{fig:mcldnn-seed-anomaly} 单独展示 MCLDNN 三个训练种子的差异。

本结果同时受以下解释边界约束：第一，与主实验矩阵的硬件不同，样本级配对自助法和 McNemar 检验无法跨硬件执行，本表仅在三种子均值层面解释，同硬件重训是获得样本级证据的必要后续工作；第二，提案主配置（\texttt{arch+aug}）的 +1.55 pp 差值来源分解见第~\ref{sec:proposed-ablation}~节的单干预消融；第三，深低信噪比（\(\le -16\) dB）准确率仍约为 \(1/11\) 的随机水平，提案模型不改变该经验下限。
