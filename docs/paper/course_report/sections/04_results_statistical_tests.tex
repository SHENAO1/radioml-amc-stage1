\textbf{关于配对统计检验独立性假设的坦白。}\label{par:independence-caveat}本章所有配对统计检验所用的 $n = 44{,}000$ 个测试样本，在按（调制类别 $\times$ SNR）联合分层后，同一 cell 内的约 1,000 个样本来自\textbf{相同的发射机仿真与信道实现}，不满足 McNemar 检验要求的逐样本独立性假设。该 cell 内相关性使有效样本量（effective sample size, ESS）可能比名义 $n = 44{,}000$ 低一到两个量级——即便保守估计 ESS $\sim 2{,}000$--$4{,}000$（每 cell 视为一个近似独立单元），大样本下任何系统性微小差异仍会产生极小 $p$ 值，但这与效应量的实际意义无关。

因此，本章\textbf{以效应量（准确率差值）与 95\% 置信区间作为主要证据}，McNemar $p$ 值\textbf{仅作辅助参考}，不单独构成"效果成立"的判据。读者应将 $p < 0.001$ 解读为"在独立性假设下方向得到支持"，而非"效应量在实际意义上足够大"。所有仅 $p < 0.001$ 的项统一标注为 ``$p < 0.001$''；决策相关的临界 $p$ 值（如 $p = 0.0155$、$p = 0.476$、$p = 0.941$）保留具体数值。

\subsection{低信噪比混淆边界推移的物理分析}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.95\textwidth]{fig14_paired_disagreement_by_snr.pdf}
  \caption{关键模型对在各 SNR 点的配对正确性净分歧（``仅 A 正确'' 占比 $-$ ``仅 B 正确'' 占比，predictions\_test.csv 三种子聚合）。}
  \label{fig:paired-disagreement-by-snr}
\end{figure}

图~\ref{fig:paired-disagreement-by-snr} 是解释低信噪比融合权衡的核心证据。它不是把两个模型的平均准确率相减，而是统计同一测试样本上"模型 A 正确、模型 B 错误"和相反方向的分歧比例，因此可以观察分歧出现在哪些 SNR 点。若 STFT 视图能提供稳定的新增判别信息，静态融合相对 I/Q 参照模型应在低信噪比区间持续出现正向净分歧；实际结果更像局部正向与局部负向的交替图谱。

相对 \path{iq_param_matched}，静态融合在 \(-14\)、\(-12\)、\(-10\) dB 的净分歧分别约为 \(+1.08\)、\(+1.74\)、\(+1.94\) 个百分点；STFT 视图在 \(-14\) 至 \(-10\) dB 区间表现出方向一致的局部正向净分歧，但单点幅度未达统计显著（单 SNR 点约 3,300 个配对样本，+1 pp 量级差异 95\% CI 宽度约为 $\pm 1.0$ pp）。在 \(-8\) 和 \(-6\) dB，净分歧转为 \(-0.80\) 和 \(-0.36\) 个百分点，表明这种局部正向分歧没有覆盖整个低信噪比区间。相对 \path{cldnn} 时，静态融合在 \(-14\) 和 \(-10\) dB 有 \(+1.35\) 和 \(+1.24\) 个百分点的局部正向净分歧，却在 \(-8\) 和 \(-6\) dB 出现 \(-1.77\) 和 \(-1.76\) 个百分点的反向分歧。这解释了为什么低信噪比总差值为 \(-0.001061\) 且置信区间跨 0：融合不是全局领先，而是在不同 SNR 点上互相抵消。

\textbf{关于单点不确定性的补充。}单 SNR 点的净分歧基于约 3,300 个配对样本（三种子合并），单点 +1 pp 量级差异的 95\% 置信区间宽度约为 $\pm 1.0$ pp，多个个别点的局部正向分歧在该不确定性下不可单独声明显著。本节的解释基于多点方向一致的整体图谱，不依赖任何单点差异。

门控融合的分歧图进一步强化负结果判断。相对静态融合，门控融合在 \(-16\) 到 \(-6\) dB 多数点为负向净分歧，其中 \(-10\) dB 约为 \(-2.50\) 个百分点，\(-12\) dB 约为 \(-1.65\) 个百分点。这说明当前标量门控没有学到"低信噪比时增加 STFT、较高信噪比时回退 I/Q"的策略，反而在静态融合已有局部正差值的位置损失了样本。

相对于 CLDNN，静态 I/Q--STFT 融合的低信噪比准确率差值为 \(-0.0011\)，95\% 置信区间为 \([-0.0039,+0.0018]\)，区间跨越 0；McNemar 检验 \(p = 0.476\)（辅助参考）。效应量与 CI 共同支持"接近但未优于 CLDNN"的解释。

相对于参数匹配 I/Q 控制模型，静态融合的低信噪比准确率差值为 0.0050，95\% 置信区间为 \([0.0020,0.0080]\)，McNemar 检验 \(p = 0.001\)。但同一比较在整体测试集上的准确率差值为 \(-0.0174\)，95\% 置信区间为 \([-0.0193,-0.0155]\)。因此，合理结论是：STFT 视图在本实现中测得低信噪比局部小幅正向差值，但伴随整体准确率下降。

图~\ref{fig:low-snr-class-recall-delta} 进一步说明，静态融合的低信噪比差异并非对所有调制类别同向。相对 \path{iq_param_matched}，静态融合在 QAM16 上的召回率下降 \(7.4\) 个百分点，却在 QAM64 上的召回率上升 \(8.9\) 个百分点，接近等幅、方向相反。这一现象的物理根源在于 \textbf{STFT 幅度谱对相位信息的不可逆丢弃}。QAM16 与 QAM64 同属正交幅度调制族，低信噪比下两者的星座点云严重重叠；区分二者的核心线索之一是相位旋转结构的细粒度差异——QAM16 的 4$\times$4 星座网格与 QAM64 的 8$\times$8 星座网格在 I/Q 平面上的相位排列不同。STFT 幅度谱作为时频能量分布的投影，\textbf{系统性地丢弃了瞬时相位信息}，构成对相位敏感特征的信息有损投影（lossy projection）。引入该视图使分类器对 QAM 子族的判别边界发生整体偏移——以 QAM16 的召回损失换取 QAM64 的召回提升。

关键在于，QAM16 召回率 $-7.4$ pp 与 QAM64 召回率 $+8.9$ pp 的接近等幅反向变化\textbf{不支持单一"干扰"假设}：若 STFT 视图仅为噪声干扰，两类 QAM 的召回率应同向下降。实际观察到的反向变化表明 STFT 幅度域投影确实携带了可供分类器利用的结构信息，但该信息使 QAM16/QAM64 之间的判别边界发生了系统性偏移，而非提供额外的类别区分度。\textbf{净效应取决于评价指标的类别权重选择——在均衡权重下，一类的召回增益被另一类的等量损失抵消。这是引入信息有损视图的固有代价，而非多视图融合所声称的"互补性"的体现。}

但本文未做 logits 分布检查、STFT 分支消融或梯度显著性归因等验证实验，因此上述物理机制保留为基于通信原理的诠释性解释，不作为因果意义上的已确立结论。附录图~\ref{fig:low-snr-confusion-panels} 给出代表模型在低信噪比范围内的行归一化混淆矩阵，作为类别混淆解释的补充。

\section{门控融合负结果}
% ============================================================

\path{gated_fusion_iq_stft} 的整体准确率为 0.5719，低信噪比准确率为 0.2113，均低于静态融合 \path{fusion_iq_stft}。配对检验也支持这一判断：门控融合相对静态融合的整体准确率差值为 \(-0.0052\)，95\% 置信区间为 \([-0.0068,-0.0035]\)，McNemar 检验 \(p < 0.001\)（辅助参考）；低信噪比范围内的差值为 \(-0.0100\)，95\% 置信区间为 \([-0.0127,-0.0073]\)，McNemar 检验 \(p < 0.001\)。

由于差值定义为"门控融合减静态融合"，上述负值说明当前标量门控机制没有改善静态融合。本文因此将门控融合作为负结果保留，不写作"门控提升鲁棒性"或"门控融合整体准确率高于静态融合"。

\textbf{门控权重 $g$ 的逐 SNR 诊断实验。}为诊断门控失败的机制，本文在 RTX 3090 上以相同三训练种子重训 \path{gated_fusion_iq_stft}（证据标签 \texttt{GATED\_FUSION\_DIAGNOSTIC\_3090}），并在测试集上提取逐样本标量门控权重 $g \in [0,1]$（$g = 0$ 表示仅 I/Q、$g = 1$ 表示仅 STFT）。三种子整体准确率分别为 0.5701 / 0.5736 / 0.5763（均值 0.5733），与 Stage 5A 主表值（0.5719）一致，确认门控融合的负结果在新硬件上可复现。

\section{MCLDNN 异常与负结果保留}\label{sec:mcldnn-anomaly}

\path{mcldnn} 三个训练种子的整体准确率为 0.5684 / 0.0909 / 0.0909，宏平均 F1 为 0.5891 / 0.0152 / 0.0152。其中 seed 42 收敛到 0.5684；seed 2025 和 seed 3407 单类塌陷至 11 类均匀基准 0.0909（宏平均 F1 0.0152），表现为近似随机水平的单类预测。seed 42 在低/中/高 SNR 子集上的准确率分别为 0.2121 / 0.7729 / 0.8391。

当前可提出三类诊断假设。第一，学习率与权重衰减组合可能不适合 MCLDNN：全模型统一使用学习率 \(10^{-3}\)、权重衰减 \(10^{-4}\)、batch size 256，有利于协议对齐，但对多分支卷积、融合卷积和 LSTM 串联的结构未必公平。第二，初始化敏感性可能更强：seed 42 正常收敛而 seed 2025/3407 塌陷，提示某些初始门控、卷积核或循环层状态可能把梯度引向退化分类头。第三，输入格式或维度排列可能与该实现的结构假设不完全匹配：MCLDNN 常依赖对 I/Q 分支、时间维和通道维的特定组织方式，若实现中的 reshape、permute 或分支拼接与预期不一致，模型可能在部分初始化下无法形成有效类别边界。

因此，沿用统一超参对 MCLDNN 公平性不足。统一学习率、权重衰减和 batch size 的优点是避免为单个模型做事后调参，保证主表比较纪律；缺点是把结构稳定性、优化敏感性和超参适配能力混在一起。更负责的后续诊断应预先登记 MCLDNN 专用学习率网格、初始化重复、梯度范数监控、输入张量形状单元测试和早期 logits 分布检查，并在新的输出目录中形成独立证据。附录图~\ref{fig:mcldnn-seed-anomaly} 单独展示 MCLDNN 三个训练种子的差异。

\subsection{提案模型 \texttt{fusion\_cldnn\_stft}+增强（跨硬件三种子均值比较）}\label{sec:results-fusion-cldnn-stft}

\textbf{硬件差异限定与效度缺口声明。}本节比较涉及两类硬件：提案模型在 RTX 3090（Ampere, sm\_86）上训练，主实验矩阵 CLDNN 基线在 RTX 4070 Ti（Ada, sm\_89）上训练。\textbf{跨硬件环境下，cuDNN 算法选择差异（不同 GPU 微架构触发不同的卷积实现路径）、浮点累加顺序差异（非确定性归约操作在不同硬件上产生不同舍入偏置）、以及可能的驱动版本与 CUDA 内核编译差异，共同构成该对比在严格意义上的效度缺口。}因此，\textbf{样本级配对自助法和 McNemar 检验在该比较中不可执行}；本节所有差值仅在三种子均值层面解释，不声明样本级统计显著性。

\textbf{归因逻辑（同硬件基线对照）。}消融中的归因应以同硬件可比基线为起点。原主实验矩阵 \path{fusion_iq_stft} 的 0.5771 来自 RTX 4070 Ti，不能直接与 RTX 3090 上的消融变体配对。表~\ref{tab:proposed-fusion-cldnn-stft-results} 已记录同硬件（RTX 3090）的延长预算对照 \path{fusion_iq_stft} 整体准确率 0.5851，该值构成架构升级的同硬件演进起点。

\begin{itemize}
\item \textbf{架构升级}（\texttt{arch\_only}，均值 0.6116）：相对同硬件基线 \path{fusion_iq_stft}@RTX3090（0.5851），架构升级的真实贡献为 $+2.65$ pp（$0.6116 - 0.5851$）。该增量的根本作用在于\textbf{缓解了原静态融合模型 I/Q 分支的表征瓶颈}——原 I/Q 分支仅 $\sim$50K 参数的一维卷积编码器，不足以在 128 步 I/Q 序列上提取与 CLDNN（241K 参数、含 LSTM 时序建模）同等水平的时序表征。将 I/Q 编码器替换为 CLDNN 风格的卷积-循环混合结构后，多视图融合重新具备与纯时域基线竞技的资格。\texttt{arch\_only} 的 0.6116 相对 Stage 5A CLDNN 的 0.6129 仅差 $-0.13$ pp，落在种子噪声范围内，说明架构升级本身\textbf{不是超越基线的来源，而是回到基线水平的必要条件}。

\textbf{辅助参照}：若以跨硬件的主实验矩阵 \path{fusion_iq_stft} 0.5771 为起点，名义增量为 $+3.45$ pp，但该对比受 RTX 4070 Ti vs. RTX 3090 的系统性偏置影响，不作为主要归因依据。

\item \textbf{信号域增强是主要涨点来源}：\texttt{arch\_aug}（0.6284）相对 \texttt{arch\_only}（0.6116）提升 $+1.68$ pp，同硬件配对检验 $p < 0.001$（辅助参考），95\% CI $[+0.0152, +0.0183]$ 不跨 0，低、中、高 SNR 均一致正向。信号域增强在架构瓶颈被缓解后进一步实现对 CLDNN 基线的超越差值。

\item \textbf{标签平滑在已有增强条件下未取得正向效应}：\texttt{arch+aug+LS}（0.6264）相对 \texttt{arch+aug}（0.6284），整体差值 $\Delta = -0.0019$（即 $-0.19$ pp），95\% CI $[-0.0033, -0.0006]$，CI 不跨 0 且完全位于负域；未校正 McNemar $p = 0.0155$。
\end{itemize}

\textbf{多重检验校正。}\label{par:multiple-testing}表~\ref{tab:proposed-paired-tests} 涉及 4 对比较 $\times$ 2 个范围（整体 / 低 SNR）$= 8$ 个 $p$ 值，构成一个比较族。在 Bonferroni 校正下，族水平 $\alpha = 0.05$ 对应的逐比较阈值为 $\alpha_{\mathrm{adj}} = 0.05/8 = 0.00625$。\texttt{proposed} vs.\ \texttt{arch+aug+LS} 整体的未校正 $p = 0.0155 > 0.00625$，\textbf{校正后不再达到统计显著阈值}\footnote{在 Holm 逐步下降法中，$p = 0.0155$ 位于 8 个排序 $p$ 值中的第 7 位，对应阈值 $\alpha/(8-7+1) = 0.025$，$0.0155 < 0.025$ 仍边际通过。本文采用更保守的 Bonferroni 报告，与全文"效应量为主"的立场一致。}。

因此，关于标签平滑的结论应表述为：\textbf{在已有信号域增强的条件下，叠加标签平滑 $\epsilon = 0.1$ 在未校正的配对 McNemar 下达到 $p = 0.0155$，但 95\% CI 不跨 0 且效应量微小（$-0.19$ pp）。多重检验校正（Bonferroni，$\alpha_{\mathrm{adj}} = 0.00625$）后该差值不再达到统计显著阈值。基于效应量为负且 CI 完全位于负域的考量，最终提案模型选择不包含标签平滑，但这是基于点估计与 CI 方向的工程选择，而非强统计支持的结论。}

\textbf{增强效果独立于融合架构。}CLDNN + aug + LS 相对 CLDNN 基线的整体准确率差值为 $+1.27$ pp（三种子 $+1.35$ / $+1.17$ / $+1.30$ pp），全部三个种子的 McNemar 检验 $p < 0.001$，bootstrap 95\% CI 均不跨零（最窄为 $[+0.92, +1.42]$ pp）。信号域增强在纯 I/Q CLDNN 上的收益与在融合架构上的收益量级一致（提案模型相对基线 $+1.20$ pp），说明增强效果\textbf{不依赖}多视图融合结构。

\textbf{融合架构贡献归零。}Proposed (\texttt{arch+aug+LS}) 相对 CLDNN + aug + LS 的整体准确率差值为 $-0.08$ pp（三种子 $+0.02$ / $-0.17$ / $-0.08$ pp），三个种子的 McNemar 检验 $p$ 值分别为 0.892 / 0.169 / 0.488，bootstrap 95\% CI 均跨零。\textbf{这意味着在同硬件配对统计检验下，融合架构相对纯 CLDNN 在同增强条件下未贡献任何可检测的独立增益。}

该发现改写了本章此前的解释框架：第~\ref{sec:results-fusion-cldnn-stft}~节报告的跨硬件 $+1.55$ pp（或同硬件 $+1.20$ pp）\textbf{完全由信号域增强驱动}，融合机制本身的独立贡献在当前统计精度下为零。提案模型的方法学新颖度因此仅限于"融合架构对信号域增强的兼容性验证"，而非"融合 + 增强的协同效应"。这一结论诚实暴露了实验设计的完整分析，符合实证研究的基本伦理。
