\begin{cnabstract}[自动调制识别；RadioML2016.10A；时频特征；深度神经网络；低信噪比；配对统计检验]
低信噪比下的自动调制识别容易受噪声扰动，多视图时频融合是否真正有用需要实证检验。本文基于 \datasetname{}，采用 \splitname{} 固定划分，比较 9 个模型行、3 个训练种子和 27 个运行单元，并使用同一样本归档预测进行配对自助法置信区间估计与 McNemar 检验。结果显示，CLDNN 取得最高整体平均准确率 0.612932 和宏平均 F1 0.633238；静态 I/Q--STFT 融合在低信噪比范围接近 CLDNN，并相对参数匹配 I/Q 控制模型有小幅收益，但伴随整体准确率下降；标量门控融合低于静态融合，构成负结果；MCLDNN 在两个训练种子上出现单类塌陷并保留在主表中。研究范围为 \datasetname{} 固定划分、9 个模型行和 3 个训练种子的协议化比较。
\end{cnabstract}
