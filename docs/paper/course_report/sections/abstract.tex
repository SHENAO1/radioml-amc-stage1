\begin{cnabstract}[自动调制识别；RadioML2016.10A；时频特征；深度神经网络；低信噪比；统计检验]
无线电自动调制识别旨在根据接收信号判别调制类别，低信噪比条件下的可靠识别仍具有挑战。本文以 \datasetname{} 为实验对象，在固定划分 \splitname{} 下比较 9 个模型行与 3 个训练种子，覆盖 I/Q 序列模型、STFT 时频分支、I/Q-STFT 静态融合、门控融合、CLDNN/MCLDNN/LWAMCNet 以及参数匹配 I/Q 控制模型。实验报告 overall、low/mid/high SNR accuracy、macro-F1 和 balanced accuracy，并基于 archived predictions 采用 paired bootstrap 与 McNemar 检验。结果表明，在当前固定协议下，CLDNN 是 strongest observed model；静态 I/Q-STFT 融合体现 low-SNR trade-off，而不是广义融合改进；门控融合未改善静态融合，应作为负结果保留；MCLDNN 的 seed 2025 与 seed 3407 chance-level collapse 继续纳入主表。上述发现仅限于 \datasetname{} 固定划分与三种子实验矩阵；latency 仅支持受控 CUDA forward latency，不外推 CPU、FLOPs/MACs、STFT 预处理完整延迟或部署效率。
\end{cnabstract}
