\chapter{总结}

\section{工作总结}

本文围绕 \datasetname{} 自动调制识别任务，完成了一份证据边界清晰的课程实验报告。报告由两层证据构成。第一层是固定划分 \splitname{} 下的 Stage 5A 主实验，共 9 个模型行 \(\times\) 3 个训练种子 \(=27\) 个运行单元，覆盖 I/Q 序列基线、STFT 时频分支、I/Q--STFT 静态融合、标量门控融合、卷积-循环混合模型、轻量模型和参数匹配 I/Q 控制模型；该层使用统一划分、统一评价指标和同一样本配对统计检验，主表数值与统计检验结果在本报告任何位置都不被覆盖。第二层是五个独立证据标签的扩展实验：训练预算延长（4 模型 \(\times\) 3 种子）、低信噪比加权交叉熵（2 模型 \(\times\) 3 种子）、扩展复杂度与单线程 CPU 延迟、低信噪比类别混淆后处理，以及一项联合架构升级、信号域增强与标签平滑的提案模型评估（1 模型 \(\times\) 3 种子）；该层使用独立输出根目录与独立证据标签登记，仅作为协议化的敏感性、干预筛查和正面贡献材料，不进入主表。

在实验组织上，报告完整记录两层证据的训练计划、评价指标、统计检验、复杂度边界与硬件设置变更，使每一项数值都能追溯到固定的证据标签与运行目录。报告写作未在 Stage 5A/5B 主实验之上启动新训练，也未把诊断性材料合并到主表。

\section{主要结论}

第一，在 Stage 5A 固定协议内，CLDNN 取得最高的整体平均准确率 0.612932 和宏平均 F1 0.633238。相对 \path{resnet1d} 和 \path{iq_param_matched}，CLDNN 的整体准确率差异在已登记配对检验中得到统计支持。该结论仅限于本报告的数据集、固定划分、模型矩阵和训练种子集合。

第二，静态 I/Q--STFT 融合体现的是低信噪比局部权衡。它在低信噪比范围内相对参数匹配 I/Q 控制模型有小幅正向差异，但相对 CLDNN 的低信噪比优势没有统计支持，并且在整体测试集上存在准确率损失。因此，本报告不能把 Stage 5A 的静态融合表述为广义优越模型。

第三，标量门控融合在本文实现中没有改善静态融合。整体和低信噪比两个范围的配对检验均显示门控融合低于静态融合，因此该模型应作为负结果保留。

第四，MCLDNN 的两个异常训练种子被保留在主表中。该处理维护了固定协议完整性，也提示当前实现存在优化或初始化敏感性。本报告不删除异常种子，不重算清洗后结果。

第五，扩展实验为主表结论提供了多角度敏感性检验。延长训练预算未明显改变主表排序也未提升低信噪比，排除“主表是欠训练造成”的常见质疑；分组 SNR 加权交叉熵在低信噪比上小幅获益但中高信噪比代价更大；8 个稳定模型在深低信噪比共同退化为对 \path{AM-SSB} 的偏置预测，构成 8 模型共同的经验下限（本文未独立论证最优分类器近似或类条件可分性，故不主张其为信息论意义下的失败下限）；扩展复杂度证据进一步显示静态融合 I/Q 分支参数量约 50K 显著低于 CLDNN 整体 242K，提示融合输给 CLDNN 是 I/Q 分支表征容量问题，MACs 数值仅作算力背景参考。

第六，提案模型 \path{fusion_cldnn_stft} 在同一固定划分与三训练种子下，由 CLDNN 风格 I/Q 编码器\cite{sainath2015cldnn,hochreiter1997lstm}与相位旋转加循环时移信号域增强（仅训练）\cite{huang2022mixingsignals,shorten2019dataaug}两项干预联合构成（\texttt{arch+aug} 配置，不含标签平滑）。相对 Stage 5A CLDNN 基线，提案模型整体准确率三种子均值 0.6284（RTX 3090），跨硬件差值 +1.55 pp，三种子标准差 0.0011；整体、低、中、高 SNR 四项指标同时正向。第~\ref{sec:proposed-ablation}~节的单干预消融把这一收益拆解为：架构升级缓解了原融合模型 I/Q 分支的表征瓶颈，使融合回到 CLDNN 量级（同硬件贡献约 $+2.65$ pp）；信号域增强在此基础上进一步贡献约 \(+1.68\) pp（主要涨点来源，同硬件配对 CI 不跨 0）。\textbf{然而，第~\ref{sec:cldnn-aug-control}~节的 CLDNN + 信号域增强对照实验揭示了决定性结论：纯 CLDNN + aug + LS 在同硬件下达到 0.6272（$+1.27$ pp，三种子均 $p < 0.001$），而 Proposed 相对 CLDNN+aug 的差值仅为 $-0.08$ pp（CI 跨零，不显著）。融合架构本身在同增强条件下未贡献任何可检测的独立增益，+1.55 pp 完全由信号域增强驱动。}本文最初登记的 \texttt{arch+aug+LS} 配置含标签平滑 0.1，但消融实验表明在已有增强条件下叠加标签平滑效应量为负（$-0.19$ pp），最终提案模型不包含标签平滑。提案模型与近期文献中复值多流\cite{wang2024ccmsnet}和 Transformer 混合方法\cite{cao2024sigformer,liu2024lenetm,li2024icrnna}的报告值量级一致，数值对比见表~\ref{tab:lit-sota-calibration}。

第七，门控融合诊断实验（第~4.4~节）揭示标量门控权重 $g$ 呈现清晰的 SNR 单调递减模式（$-20$ dB 时 $g \approx 0.79$、$+18$ dB 时 $g \approx 0.12$），说明门控网络确实学到了 SNR 条件信息，但这一正确的门控方向未转化为分类增益（整体准确率仍低于静态融合），且 $g$ 的跨种子稳定性差（均值 0.18--0.34）。

\section{不足与后续工作}

本报告最主要的局限来自实验范围。主结果只覆盖 \datasetname{} 和单一固定划分，没有纳入 RadioML2018.01A、真实外场信道或多划分重复验证；复杂度证据虽已补全 MACs/FLOPs 与单线程 CPU 延迟，仍不能等同于完整部署效率（CPU 多线程、ARM/移动/DSP、STFT 预处理完整成本均未独立测量）。本轮补充实验已消除此前最关键的两个缺口：同硬件配对检验（\texttt{EXTENDED\_BUDGET\_3090} + \texttt{CLDNN\_AUG\_ABLATION\_3090}）已完成，门控融合诊断（\texttt{GATED\_FUSION\_DIAGNOSTIC\_3090}）也已执行。

后续工作可以沿四条方向推进。其一，多 stratified split 敏感性验证（至少 2--3 个划分种子），确认主表排序与增强收益在划分随机性下的稳健性。其二，既然融合架构贡献归零（第~\ref{sec:cldnn-aug-control}~节），后续方向应转向更强的 I/Q 编码器：沿文献中最一致涨点方向（复值网络如 CC-MSNet\cite{wang2024ccmsnet} 系列、Transformer 混合如 SigFormer\cite{cao2024sigformer} 系列）实现更强的 I/Q 编码器或注意力组件，目标对齐 LENet-M 0.6463 / SigFormer 0.6371 区间。其三，对比 \texttt{arch\_aug} 与 \texttt{arch\_only} 的逐 SNR 准确率差值，确认信号域增强收益的 SNR 分布，并补充 \path{fusion_iq_stft} 模型在低 SNR QAM16/QAM64 子集上的 logits 分布分析与梯度显著性归因，验证第~4.3.1~节提出的 STFT 幅度域相位丢弃导致判别边界偏移的物理机制假设。其四，在 RadioML2018.01A 子集上以相同模型身份、统计检验与证据标签复核主表排序与增强收益的可重复性。
