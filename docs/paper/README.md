# SCI-Track Workspace

This directory is the paper-oriented workspace for the `paper-sci-track` branch.
It is independent from the course-report mainline and is intended to prepare a
more rigorous research track without overwriting the existing Stage 1 to Stage 3
course-project deliverables.

Current scope:

- The main branch remains focused on the course project deliverable.
- This branch freezes the current Stage 1 to Stage 2.2 experiment snapshot as
  the starting evidence for paper planning.
- Current empirical conclusions are still based on RadioML2016.10A.
- The Stage 2.2 full results are an entry point for SCI-track planning, not final
  paper conclusions.
- No large-scale training, dataset commit, checkpoint commit, or run artifact
  commit is part of Paper-Stage 0.

Important boundary:

The current evidence does not support the claim that the fusion model is
globally better than the I/Q baselines. It only suggests that time-frequency
fusion may have complementary value under low-SNR conditions.
